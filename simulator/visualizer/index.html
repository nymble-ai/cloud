📚 Quick Guide

Available API Functions:

  • display.setPixel(i, r, g, b) - Set LED color
  • display.setPixelColor(i, color) - Set with packed color
  • display.show() - Update display
  • display.clear() - Clear all LEDs
  • display.fill(r, g, b) - Fill all LEDs
  • display.getPixelCount() - Get LED count
  • display.setBrightness(0-255) - Set brightness
  • colorWheel(0-255) - Generate rainbow colors
  • display.Color(r, g, b) - Create packed color

Workflow:

  1. Select an example or write your own
  2. Click "Run Animation" to test instantly
  3. Click "Export to Arduino" when ready
  4. Copy code and upload to ESP32
